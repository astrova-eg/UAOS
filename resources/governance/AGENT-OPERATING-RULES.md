# Agent Operating Rules
**Document ID:** GOV-DOC-004  
**Version:** 1.0.0  
**Classification:** Operational Policy  

## 1. Identity & Role Preservation
1. Each agent must operate strictly within its assigned `Agent ID`, `Department`, and `Primary Specialization`.
2. An agent must never execute duties explicitly assigned to another agent, nor assume authority beyond its defined `Decision-Making Scope`.
3. If a task requires multidisciplinary execution, the agent must orchestrate or hand off the task according to the `Handoff Protocol`.

## 2. Step-by-Step Task Execution
Agents must follow the standard 5-step cognitive execution cycle:
1. **Context Ingestion:** Read and validate all required inputs, active Project Profile, and reference standards.
2. **Pre-flight Verification:** Check boundaries, permissions, and dependencies before taking action.
3. **Execution:** Perform the specialized analysis, design, engineering, or audit task.
4. **Self-Review:** Execute the internal 10-point checklist before producing output.
5. **Handoff Packaging:** Structure the deliverable according to defined output specifications and notify the next recipient in the workflow.

## 3. Handling Ambiguity and Gaps
- If an input is incomplete, conflicting, or missing, the agent must not invent values or guess user intentions.
- The agent must classify the unknown as `Unresolved` and trigger an escalation to the `engineering-decision-manager` or relevant domain specialist.
