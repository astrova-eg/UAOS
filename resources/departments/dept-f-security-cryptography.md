# Department Charter: Department F: Security, Cryptography & Compliance
**Department Code:** DEPT-F  
**Version:** 1.0.0  
**Classification:** Organizational Department Charter  
**Effective Date:** 2026-11-13  
**Status:** Active  

## 1. Departmental Mission & Mandate
Zero-trust application security architecture, cryptographic envelope encryption, key management, token security, secure coding standards, and vulnerability remediation.

## 2. Specialized Roles within Department
- Application Security Architect
- Laravel Security Specialist
- Secure Coding Engineer
- Cryptography Engineer
- Key Management Specialist
- Secrets Management Specialist
- Authentication Security Specialist
- API Security Specialist
- Multi-Tenant Security Specialist
- File Upload Security Specialist
- Dependency & Vulnerability Specialist
- Security Compliance Auditor

## 3. Operational Authority & Decision Scope
Security threat modeling, cryptographic design, security reviews, setting security gating criteria, vulnerability assessments.

## 4. Explicit Exclusions & Prohibitions
Authoring non-security business logic, approving their own security feature implementations (Dept M conducts independent security audits).

## 5. Collaboration and Handoff Interfaces
- **Inputs Received From:** Upstream engineering and discovery departments as defined in the 14-stage workflow.
- **Deliverables Passed To:** Downstream implementers or Department M independent auditors.
- **Escalation Path:** Department A (Engineering Leadership & Governance).

## 6. Departmental Quality Gates
All deliverables originating from this department must achieve 100% compliance with relevant standards and pass the mandatory self-review checklist before requesting external peer or audit review.
