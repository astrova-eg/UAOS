## 1. Overview
Welcome to the Universal Core onboarding guide. This domain provides everything a new developer or autonomous agent needs to install, configure, verify, and begin developing on Universal Core.

### Environmental Baseline
- **Operating System:** Windows native workstation.
- **Local Stack:** Native Windows Laragon with PowerShell console.
- **Runtimes:** PHP 8.3+, MySQL 8.4 LTS, Redis service, Composer 2.x, Node.js 20+.
- **Strict Prohibitions:** Docker and Laravel Sail are strictly prohibited as local development requirements.
