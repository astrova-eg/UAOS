## 1. Review Directives
Reviewers inspect correctness, architecture compliance, security invariants, database performance, and test coverage using standard severity levels (`[BLOCKER]`, `[IMPORTANT]`, `[SUGGESTION]`, `[NITPICK]`, `[QUESTION]`).
