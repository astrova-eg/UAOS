## 1. PR Lifecycle
```text
Branch Creation -> Local Tests -> Push Branch -> Open PR -> CI Passes -> Peer Review -> Squash & Merge -> Branch Deleted
```
- PR descriptions must explain motivation, changes, test evidence, and documentation impact.
- Merges to `main` use **Squash and Merge** by default to maintain a clean linear history.
