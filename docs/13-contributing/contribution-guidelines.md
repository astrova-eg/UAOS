## 1. Contribution Principles
1. Work is performed on dedicated short-lived branches (`feature/`, `bugfix/`, `docs/`).
2. Code and documentation updates must be submitted together in atomic PRs.
3. Commits must follow Conventional Commits 1.0.0.
4. All local tests, Pint styling, and PHPStan analysis must pass prior to opening a PR.
