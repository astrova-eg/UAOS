## 1. Versioning Semantics
- `MAJOR`: Incompatible API contracts, breaking schema changes, architectural overhauls.
- `MINOR`: New backward-compatible features, endpoints, or core systems.
- `PATCH`: Backward-compatible bug fixes, security patches, and documentation updates.
