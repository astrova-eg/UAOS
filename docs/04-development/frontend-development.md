## 1. RTL-Native & Tailwind Directives
- All Blade views, Livewire components, and Filament panels must be RTL-native using logical Tailwind classes (`ps-`, `pe-`, `start-`, `end-`).
- Adhere to WCAG 2.1 AA accessibility guidelines (semantic HTML, proper ARIA attributes, keyboard navigation).
