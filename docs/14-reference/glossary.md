## Terms
- **Action Class:** An invokable, single-responsibility class encapsulating a discrete business use case.
- **DTO (Data Transfer Object):** A typed, immutable data structure transferring data between architectural layers.
- **Tenant Scope:** A global Eloquent query filter restricting all database reads and writes to the active organization.
- **Envelope Encryption:** A two-tier cryptographic pattern using a data key to encrypt data and a master key to encrypt the data key.
