## 1. Core Ownership Domains
- **Department N (Documentation & System Closure):** Overall governance of `docs/` structure, indexing, quality gates, and system closure verification (`DOC-001`, `APIDOC-001`, `ADR-001`, `CLOS-001`).
- **Domain Producer Agents:** Responsible for authoring domain-specific specifications and runbooks (e.g., Department E for Database Dictionaries, Department F for Security Architecture, Department L for DevOps Operations).
- **Department M (Independent Audit):** Audits documentation accuracy against executable code during verification gates (`AUD-001` through `AUD-008`).
