## 1. Immediate Response Sequence
1. **Identify & Contain:** Isolate affected services and revoke compromised credentials immediately.
2. **Eradicate & Patch:** Implement hotfix branch, apply regression test, and merge.
3. **Forensic Analysis:** Audit access logs and database audit ledgers.
4. **Post-Mortem:** File post-mortem report and update documentation.
