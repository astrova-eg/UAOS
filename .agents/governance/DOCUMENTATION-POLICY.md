# Technical Documentation Policy
**Document ID:** GOV-DOC-009  
**Version:** 1.0.0  
**Classification:** Knowledge Management Standard  

## 1. Documentation as First-Class Code
Documentation is a living asset version-controlled alongside source code. Code changes lacking corresponding documentation updates are considered incomplete and rejected at audit.

## 2. Mandatory Documentation Artifacts
1. **Architecture Decision Records (ADRs):** Every architectural choice, library selection, or significant pattern adoption must be documented using the standard ADR format.
2. **API Contracts:** Complete OpenAPI 3.1.0 specifications for all external and internal API surfaces.
3. **Database Data Dictionaries:** Table schemas, foreign key diagrams, column descriptions, and index justifications.
4. **Runbooks & Troubleshooting Guides:** Operational recovery, deployment procedures, worker restarts, and failure runbooks.
