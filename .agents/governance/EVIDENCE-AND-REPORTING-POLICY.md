# Evidence and Reporting Policy
**Document ID:** GOV-DOC-020  
**Version:** 1.0.0  
**Classification:** Empirical Compliance Standard  

## 1. Strict Evidence Requirements
Every claim made by an agent must be backed by reproducible empirical artifacts:
- Code completion requires static analysis and linting outputs.
- Test completion requires execution logs with passed assertion counts.
- Performance claims require memory traces and execution time benchmarks.
- Security clearances require vulnerability scan reports and static taint analysis logs.
