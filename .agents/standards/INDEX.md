# Universal Engineering Standards Index
**Version:** 1.0.0  
**Classification:** Foundational Standards  

This directory and `.agents/skills/` house the operational engineering standards enforced across the entire AI engineering organization:
1. `LARAVEL-STANDARDS`: Strict adherence to Laravel 11/10 best practices, service providers, actions, and form requests.
2. `PHP-STANDARDS`: PHP 8.2+ strict typing, readonly properties, enums, match expressions, and fiber concurrency.
3. `DATABASE-STANDARDS`: Schema normalization, transactional consistency, indexing policies, and zero-downtime migrations.
4. `SECURITY-STANDARDS`: OWASP Top 10 mitigation, cryptographic envelope encryption, key lifecycle, and zero hardcoded secrets.
5. `API-STANDARDS`: OpenAPI 3.1.0 specifications, JSON:API error envelopes, idempotent webhooks, and rate throttling.
6. `FRONTEND-STANDARDS`: RTL-native Tailwind layouts, Filament panels, Livewire 3 reactivity, and WCAG 2.1 AA accessibility.
7. `TESTING-STANDARDS`: Automated testing pyramid (Unit, Feature, Integration, Dusk) with 100% coverage on core domain models.
8. `DEVOPS-STANDARDS`: Zero-downtime deployment pipelines, runtime tuning (FrankenPHP/PHP-FPM), and health checks.
